## Overview

Minecraft 1.20 is the latest stable Java Edition release, bringing new blocks, mobs, and gameplay enhancements.  
Fully compatible with modern mod loaders like **Forge** and **Fabric**, it’s perfect for modded servers and custom worlds.

## How to Play

### Official Java Edition
1. Open **Minecraft Launcher**.
2. Select **1.20** version.
3. Click **Play**.

### Browser Ports
- **[Eaglercraft](https://eaglercraft.dev/)** – Play 1.20 in browser, create worlds, join servers.  
- **[Web Edition](https://www.mcraft.fun/)** – Browser Minecraft for quick play (limited features).

### Mods
- Install **Forge** or **Fabric** for 1.20 to use mods and resource packs.

---

## Installation (Forge Example)

1. Download Forge for **Minecraft 1.20** from [Forge.net](https://files.minecraftforge.net/).
2. Open the installer and select **Install client**.
3. Launch **Minecraft Launcher**, choose **Forge profile**, click **Play**.
4. To install mods, place `.jar` files in `.minecraft/mods` folder.

---

## Chromebook Notes
- Enable **Linux (Crostini)** on your Chromebook.
- Install Minecraft for Linux.
- Alternatively, use **browser ports**.
