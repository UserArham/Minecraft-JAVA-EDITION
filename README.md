## Overview
Minecraft 1.20 is the latest stable Java Edition release, introducing exciting features and gameplay improvements.  
It is fully compatible with modern mod loaders such as **Fabric** and **Forge**, making it ideal for modded servers and custom content.

---

## Key Features

- **New Blocks and Items**
  - Cherry Wood, Cherry Planks
  - Hanging Signs
  - Sniffer Eggs
  - Bundle and Brush Items
  - New Mobs: Sniffer, Allay, Camel

- **Gameplay Enhancements**
  - Archaeology system
  - Advanced mob behaviors and AI
  - Improved biome and world generation
  - Customizable world features

- **Performance & Stability**
  - Optimized Java Edition performance
  - Enhanced multiplayer server efficiency
  - Bug fixes from previous releases

---

## System Requirements

- **OS:** Windows, macOS, Linux  
- **RAM:** Minimum 4GB (6GB+ recommended for mods)  
- **Java:** Java 17 or later  
- **CPU/GPU:** Any modern processor and GPU capable of OpenGL 3.0+

## How to Play

### Official Java Edition
Use the **Minecraft Launcher** and select version **1.20**.

### Browser Ports (Unofficial)
- **[Eaglercraft](https://eaglercraft.dev/)**  
- **[Web Edition](https://www.mcraft.fun/)**  

These allow running Minecraft 1.20 (or older versions) directly in your browser.

### Mods
- Use **Forge** or **Fabric** for 1.20 to install mods, resource packs, and custom server packs.

## Installation (Forge Example)

### Step 1: Download Forge
1. Go to the official Forge website.
2. Choose **Minecraft 1.20**.
3. Click **Installer** under **Download Latest**.

### Step 2: Run the Installer
1. Open your **Downloads** folder.
2. Double-click the Forge installer.
3. Select **Install client**.
4. Click **OK** and wait for confirmation.

### Step 3: Launch Minecraft
1. Open the **Minecraft Launcher**.
2. Select the **Forge** profile.
3. Click **Play**.

### Optional: Installing Mods
1. Press `Win + R`, type `%appdata%`, and press Enter.
2. Open the `.minecraft` folder.
3. Open or create the `mods` folder.
4. Place mod `.jar` files into the folder.
5. Launch Minecraft using the **Forge** profile.
